# État des constats de l'audit (novembre 2026)

Relevé fait sur l'arbre de travail du 26 novembre 2026 (commit `08ac017` + modifications non
commitées des chantiers « stockage local », « performance » et « qualité »). Chaque état a été
vérifié dans le code. Chaque test cité existe et passe : `pnpm test` (226 fichiers),
`pnpm test:sql`, e2e Chromium.

- **Gravité** : celle retenue après la contre-vérification de l'audit (P0 = perte de données
  ou faille majeure, P3 = hygiène).
- **Identifiants** : l'audit a deux listes « F ». La liste « synchronisation » garde `F1`…`F14` ;
  la liste « stockage local et mobile » est notée `F1q`…`F11q`.
- **États** : _Corrigé_ (preuve par un test) ; _Partiel_ (le risque principal est traité, un
  reste est décrit) ; _Accepté_ (choix documenté, pas de changement de code) ; _Non corrigé_.

Documents liés : `docs/architecture/sync.md` (§ 4 et tableau final),
`docs/architecture/security.md`, `docs/architecture/code-quality.md`.

## 6. Risques restants, classés

1. **(P2) Tests non vérifiés par TypeScript (QA-06)** : 475 erreurs de type dans `tests/` si on
   les compile. Un mock faux peut faire passer un test à tort. À faire : `tsconfig` des tests,
   correction par lots, puis ajout à `pnpm typecheck`.
2. **(P1, partiel) Restauration de sauvegarde en mode « remplacer tout » (F5q)** : protégée par
   aperçu, confirmation et annulation, mais une pesée ou une mensuration saisie après la
   sauvegarde disparaît si l'utilisateur confirme et clique « Garder ». À faire : fusion par
   clé avec les stratégies de `domain-merge`.
3. **(Exploitation) iOS non compilé** avec Capacitor 8.6.2 (QA-07) : à vérifier sur Mac/CI
   iOS avant publication.
4. **(Exploitation) Migrations 010/011 à appliquer en production** dans l'ordre, avec
   sauvegarde préalable et contrôles (security.md § 5). Concurrence testée sur Postgres 16
   local avec un shim, pas sur une instance Supabase réelle.
5. **(P3) Suppression de compte sans réauthentification récente (SEC-11)** : un jeton volé
   suffit. À faire : `supabase.auth.reauthenticate()` côté UI.
6. **(Sécurité, hors code) Pas de CAPTCHA à l'inscription** : comptes jetables × 50 Mo
   possibles ; coût IA borné par `daily_global_unpaid`, pas le stockage.
7. **(P2, partiel) Stockage plein pendant une séance (F9q)** : l'utilisateur est prévenu,
   mais l'espace libérable n'est pas indiqué.
8. **(P3) Dette de structure** : `seances()` géant (QA-11), notifications dupliquées (QA-14),
   `UuidGenerator` dans deux pages (QA-12). Plans dans `code-quality.md`.
9. **(Budget)** JS initial 121,6 / 130 KiB, total JS 343,5 / 350 KiB : peu de marge sur le
   total.
10. **(P3) Écritures « récents » de nutrition** sans message d'échec (QA-08), cache
    `loadSessions` aveugle à une réécriture hors module (PERF-11), tables mortes conservées
    (PERF-12).
